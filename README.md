🚀 WorkSpera

WorkSpera is a modern professional networking platform that blends the power of career networking (like LinkedIn) with social interaction (like Instagram) to create a dynamic collaboration space for professionals.

✨ Key Highlights
🔐 Secure Authentication with OTP & OAuth
🧑‍💼 Professional Profile & Resume Parsing (AI-powered)
📰 Social Feed with Posts, Polls, and Reactions
💬 Real-time Chat & 📞 Video Calling (WebRTC)
🤖 AI Integration using Google Gemini
📸 Instagram-style Stories System
🛡️ Admin Dashboard & Content Moderation
🔐 Authentication & Security
Secure Sign Up & Login with smooth animations
OTP Verification using Nodemailer (Gmail SMTP)
Protected Routes using NextAuth JWT (getToken)
Google OAuth + Credentials login
Blocked users are restricted from accessing the platform
🖥️ Dashboard & User Experience
Fully responsive UI (desktop + mobile)
Sidebar navigation with smooth animations (Framer Motion)
Real-time online/offline status using Socket.IO
Seamless page transitions
👤 Profile & Portfolio
Profile image & cover photo (Cloudinary)
Bio, professional summary, and skills
Educational timeline
Resume upload (PDF/DOC)
🌟 AI Resume Parsing (Gemini) to auto-fill profile
Social links integration
Public profile viewing
📰 Posts & Feed System
Create posts with images & captions
Multi-image grid layout
Save/bookmark posts
Edit & delete posts
Post visibility control (Public / Private / Followers)
Hashtags for discoverability
📊 Poll System
Create polls within posts
Real-time voting results
One vote per user
Highlighted user selection
❤️ Interactions & Notifications
Reactions
Multiple reaction types (Like, Love, Celebrate, etc.)
Animated reaction picker
View who reacted
Comments
Nested replies
Expand/collapse replies (Instagram-style)
Notifications
Real-time notifications (polling every 30s)
Types: follow, like, comment, message, job alerts
💬 Messaging & Video Calls
Chat
Real-time messaging (Socket.IO)
Typing indicators
Read receipts (sent → delivered → seen)
Image sharing
Soft delete messages
Video Call
WebRTC-based video calling
STUN + TURN server support
Incoming call UI
Audio/video controls
🤖 AI Features
💬 AI Chatbot (Google Gemini)
🔍 AI Job Search (semantic search)
📄 AI Resume Parsing
📸 Stories Feature
Instagram-style stories (24-hour expiry)
Story likes & viewers tracking
Story upload & management
🛡️ Admin Dashboard
User management (block/unblock, role control)
Platform analytics
Report management system
Content moderation tools

Layer	Technology
